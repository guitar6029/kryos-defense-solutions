# Engineering Concepts

This directory is a lightweight knowledge base for engineering concepts that come up while building Kryos Defense Solutions. The notes are meant to support practical learning and technical discussion, not to serve as formal product documentation or a textbook.

Each note connects a general concept to the implementation currently in the repository. Start with the problem, inspect the linked code, and use the trade-offs to understand why a particular approach was chosen. The simulator and telemetry paths are deliberately treated as implemented only where the code and tests support that claim.

Keep notes concise, practical, and grounded in the actual codebase. When an implementation changes, update the relevant note instead of creating a duplicate document. Add a new note only when the concept is genuinely distinct.
